# 滑动变阻器

> V4 Pro 一日不来，滑片一日不归零。

这是一个把互联网新梗做成物理实验器材的网页小玩具。

刻度盘上写着「梁神」「梁圣」「梁子」「牢梁」，滑片里装着梁文锋的头像。你可以亲手推动滑片，听着齿轮和金属摩擦声，感受网友对 DeepSeek 的期待值在崇拜、等待和催更之间来回移动。

## 这个梗是怎么滑过来的

最开始，网友称 DeepSeek 创始人梁文锋为「梁圣」。这个称呼带着真心的佩服，多少也有一点互联网式的造神气质。

后来，围绕 DeepSeek V4 发布节奏的等待越拖越长，大家的耐心跟着更新进度一起波动。称号也开始降档，从「梁圣」滑到「梁子」，再一路滑向「牢梁」。

这里的「牢」借了网络流行称呼「牢大」的语感，专门用来调侃那个让大家守着消息、反复刷新、迟迟等不到新产品的人。等得再久一点，称号甚至还能继续滑到「梁白开」。

这些称号没有固定档位。消息振奋时，他是梁圣。等待拉长时，他成了梁子。再跳几次票，滑片便稳稳停在牢梁。网友一边催，一边等，一边继续用，多少有点爱之深，催之切。

于是，这台滑动变阻器出现了。互联网情绪终于有了刻度，也有了机械摩擦声。

## 这台变阻器能干什么

- 真能滑。支持鼠标拖动、手机触控、滚轮和键盘操作，还有惯性、阻尼与刻度反馈。
- 真会响。滑动时会实时生成机械摩擦、齿轮碰撞和刻度咔哒声，手机上还带轻微震动反馈。
- 随你改。头像可以上传，上方称号和主体文案都能修改，颜色、强调色与字号也能自由调整。
- 手机也能玩。横屏和竖屏会自动适配，设置面板在小屏幕上会变成底部抽屉。
- 可以存图。点击「保存图片」即可导出当前变阻器，头像、文案、颜色和滑片位置都会一起保存为高清 PNG。
- 记得住进度。你的设置会保存在浏览器里，下次打开还能接着催。
- 价格会自己追。页面每 5 分钟从 DeepSeek 官方定价页同步 V4 Flash 与 V4 Pro 的输入、输出价格，并按 V4 Flash 输入价自动移动滑片。

## 价格档位

页面以 `deepseek-v4-flash` 的“缓存未命中输入价”为依据，单位为每百万 tokens：

- 不高于 1 元：梁神
- 不高于 2 元：梁圣
- 不高于 3 元：梁子
- 超过 3 元（包括 4 元及更高）：牢梁

输出价格与 `deepseek-v4-pro` 只作实时展示，不参与滑片档位判断。

## 怎么玩

1. 拖动头像滑片，选择今天的梁文锋称号。
2. 打开「自定义」，换头像、改文案、调颜色和字号。
3. 开启机械音效，让每一次催更都更有仪式感。
4. 点击「保存图片」，把今日称号发给同样在等更新的朋友。

## 本地运行

本地开发没有构建步骤。由于 DeepSeek 官方页面不允许浏览器直接跨域抓取，请使用项目自带的 Node.js 服务，它会同源提供 `/api/pricing.json` 接口：

```bash
node server.js
```

然后打开 `http://localhost:8080`。需要 Node.js 18 或更高版本。

## 线上部署

线上服务器保持纯 Nginx 静态托管，不需要安装 Node.js、npm、Playwright 或浏览器。

**站点部署（GitHub Actions）**：推送到 `main` 或手动触发工作流时部署完整站点。工作流先跑解析测试，再抓一次官方定价生成 `api/pricing.json` 随站点一起发布，最后从线上地址验证页面标识和两个模型的四项价格。

**实时价格刷新（服务器 systemd timer）**：真正让价格"每 5 分钟更新一次"的是服务器上的 `laoliang-pricing.timer`，它每 5 分钟拉取 DeepSeek 官方定价页并原子写入 `api/pricing.json`。GitHub Actions 不再跑定时任务（公开仓库的 schedule 触发不可靠，且与服务器 timer 冗余）。

运行解析测试：

```bash
node --test server.test.js
```

浏览器会在你第一次点击或拖动后允许播放声音。如果刚打开时没有机械声，它没有罢工，只是在等你先动手。
